# ISA-100: wireless scope

Use when a request cites ISA-100 as interface guidance.

[ISA-100](https://www.isa.org/standards-and-publications/isa-standards/isa-100-standards) addresses industrial wireless systems. It is distinct from [ISA-101's HMI scope](isa-101.md). Verified 2026-11-15.

For a dashboard design task, clarify the reference and use ISA-101 for HMI context. If the product actually configures an industrial wireless system, keep its wireless requirements separate from UI principles and consult the applicable licensed standards. This skill supplies neither wireless engineering requirements nor ISA-100 compliance checks.
