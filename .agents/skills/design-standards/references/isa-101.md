# ISA-101: industrial HMI context

Use when reviewing operational dashboards, exception emphasis, or an industrial HMI requirement.

## Source and scope

[ISA-101](https://www.isa.org/standards-and-publications/isa-standards/isa-101-standards) concerns human-machine interfaces for process automation, including the HMI lifecycle and operator effectiveness. Verified 2026-11-15. The full copyrighted standard is not bundled or summarized clause by clause here.

Treat this as domain context. An ordinary web dashboard using restrained colors is not thereby ISA-101 compliant. For industrial safety or contractual compliance, obtain the applicable edition, licensed requirements, and domain review.

## Apply the product heuristic

Use quiet normal surfaces and restrained emphasis so actionable exceptions are noticeable. Pair state color with words and, when useful, symbols. Keep controls, text, and focus visible; quiet styling must preserve accessibility.

Distinguish urgency from decoration. Give an exception a clear state, cause, and useful next action. Avoid making every message look like an emergency. Actual alarm priority, acknowledgement, escalation, and safe response require process-specific engineering.

The quiet-normal-state rule is this playbook's design heuristic, not a quoted ISA clause or a universal industrial palette mandate.
