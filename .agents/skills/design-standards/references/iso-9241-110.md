# ISO 9241-110: interaction

Use for task flow, control behavior, feedback, correction, and learning.

## Source and scope

[ISO 9241-110:2020](https://www.iso.org/standard/75258.html), edition 2, covers interaction principles and is current after confirmation in 2025. Its public scope distinguishes interaction from aesthetics and corporate identity. Verified 2026-11-15.

The applications below are this playbook's original synthesis. They are not quoted clauses, an exhaustive account of the standard, or a compliance assessment. Use licensed text for clause-level work.

## Apply to the task

- Define a screen by the outcome it supports: "Grant this agent search access to these folders," rather than "Display permission cards."
- Put the frequent action near its target. Place rare options behind a descriptive disclosure while leaving important consequences visible.
- Use familiar domain words and predictable controls. Use the same term for the same behavior across screens.
- Choose an explicit change contract: immediate application, staged Save, or an asynchronous operation. Explain the effect at the action, including dependencies or affected scope.
- Preserve valid input after an error. Identify the problem and useful correction beside the field; keep a route back or undo when safe.
- Confirm success only when known. During a delay, show that work is pending and what the person can do next.
- Make confirmation proportional to consequence so routine reversible changes do not train people to ignore warnings.

## Review evidence

Run one representative task, a blocked attempt, and recovery from an error. Record whether the person can find the action, predict its effect, distinguish pending from completed work, and recover without re-entering valid data.

For an access-management example: select an agent, request Search Documents, explain why Edit Document is blocked, predict what Save will change, and recover from a failed save. This is an illustrative product task, not an ISO-prescribed test.

Use [ISO 9241-112](iso-9241-112.md) when the failure concerns information presentation; use [WCAG](wcag-22.md) for accessibility criteria.
