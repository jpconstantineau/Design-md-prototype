# HSE: control-system feedback and alarms

Use for publicly accessible operational feedback and alarm-presentation guidance.

## Source and application

[HSE control systems guidance](https://www.hse.gov.uk/comah/sragtech/techmeascontrol.htm), verified 2026-11-15, discusses operator interfaces, action and delay feedback, correction of mistakes, standardized alarm information, and consistent coding with redundant cues alongside color.

For a software dashboard, apply that guidance by showing pending/completed actions, describing delays, supporting safe correction, and placing a clear state, cause, and response with an exception. Pair color with readable text or an appropriate symbol; keep coding consistent across screens.

This is an original application to software, not an assertion that HSE mandates a muted palette or certifies the product. Use [ISA-101](isa-101.md) for the industrial scope and [WCAG](wcag-22.md) for accessibility tests. Industrial safety, alarm prioritization, and control-system design need their own domain review.
